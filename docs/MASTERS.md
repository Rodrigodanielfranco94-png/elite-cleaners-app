# Production masters

This repository contains the production-facing Elite Cleaners applications.

## Elite Admin

- File: `admin.html`
- Current master title: **Elite Admin v9.0.29**
- Responsibility: administration, clients, services, payments, accounting, inventory, reports and business operations.

## Elite Staff

- File: `staff_v3.html`
- Current master title: **Elite Staff v9.6 FIXED**
- Responsibility: employee workflow, job states, GPS snapshots, photos, checklists, pauses and staff reports.

## Supporting page

- `firmar.html` — signature workflow.
- `index.html` — current repository entry page.

## Rule

Changes to Admin or Staff should be made independently and reviewed as app-specific changes. Elite Command consumes shared Firebase data and should not require copying Admin/Staff source into its own repository.
